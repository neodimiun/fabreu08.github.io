# joseqc.com

Personal site for José A. Fernández Abreu, M&PT Engineer at Collins Aerospace Landing Systems.

Source lives in `site/` (React, TypeScript, Vite, Tailwind). GitHub Pages serves the built files from the repo root.

```bash
cd site
npm install
npm run dev          # local
npm run build:pages  # writes ../index.html and ../assets
```
